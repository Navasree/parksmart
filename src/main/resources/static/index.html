System Pricing Architecture

Spring Boot Enforced

These pricing tiers are configured and calculated permanently within the backend billing engine (ParkingBillService). All calculations use high-precision BigDecimal with ceiling rounding.

First Hour Base Rate Minimum stay fee applied to the first 60 minutes
₹30.00
Additional Hour Rate Applied per each subsequent hour (CEIL(duration / 60) - 1)
₹20.00 / hr
Overstay Penalty Rate Enforced when actual checkout exceeds scheduled booking end
₹50.00 / hr
Notice on System Configuration:

Rates are enforced directly by the Spring Boot calculation engine to guarantee data integrity in MySQL. Frontend reflects these rules without independent deviation.

Architecture: Controller → Service → Repository → Entity
